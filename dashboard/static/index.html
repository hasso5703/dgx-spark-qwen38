Safety belts 

          

            
Memory floor
...

            
Driver refusals (1 h)
...

            
Prefix cache guard
...

          

          
The floor belt aborts every generation when host memory falls under the floor while requests run. Driver refusals are recoverable allocation failures during a prefill near the memory edge; the engine retries them. The prefix cache guard empties the radix cache while the engine is idle above its threshold, so a later giant prompt never has to evict: the cost is that the next long prompt prefills from scratch.
