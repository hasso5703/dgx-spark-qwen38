Spark Cockpit: two design directions to choose from

Static mockup, real shapes from the box (29/08 evening). Same content in both: the KV pool as the hero instrument, the two lanes, live requests, the boot timeline. Nothing here is wired; it is a conversation piece for tomorrow.

Current app: graphite, gold, NVIDIA green, cards. Both directions below drop the card grid for one strong instrument and a stricter type system, and each takes one deliberate risk.

Direction A: Instrument. A telemetry console: one monospace family for everything, uppercase tracked labels, a ruled scale as the hero (held tokens, the one-prompt cap as a needle, the 262K window dashed), lanes as a switchboard, boot stages as segment lights. Risk taken: monospace for all text, not only numbers. For long sessions in a dark room.
